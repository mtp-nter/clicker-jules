# Cookie Clicker Web Application

A simple, responsive web application featuring a centered clickable cookie with a click counter, smooth animations, persistent score using `localStorage`, and a reset option.

## Features

- **Interactive Cookie**: A centered custom SVG cookie that scales and reacts on click and hover.
- **Click Counter**: Real-time click counter displaying the total number of times the cookie has been clicked.
- **Click Effects**: Floating `+1` particle animations that appear on each click.
- **Persistence**: Remembers your click count across page reloads using browser `localStorage`.
- **Reset Button**: Allows resetting the cookie click counter back to zero.
- **Responsive & Modern UI**: Built with HTML, CSS, and vanilla JavaScript without external framework dependencies.

## Usage

Simply open `index.html` in any modern web browser to start clicking the cookie!
